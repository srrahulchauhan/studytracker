# StudyFlow (StudyTracker) 📚⚡

A modern, high-performance study tracker and smart learning management dashboard designed for students and self-learners.

## ✨ Features

- ⏱️ **Pomodoro Study Timer**: Custom focus intervals, rest breaks, ambient noise generator, and audio cues.
- 🎯 **Targets & Goals Tracker**: Daily & weekly study targets, micro-goals, and milestone celebrations with confetti.
- 📅 **Dynamic Timetable & Calendar**: Smart schedule planning with conflict checking and recurring study plans.
- 📚 **Syllabus & Topic Management**: Preparations, subject breakdowns, topic statuses, video link bookmarks, and priority tags.
- 🔁 **Revision Hub**: Spaced repetition, revision queues, and quick flash-review modals.
- 📊 **Deep Analytics & Attendance**: Attendance percentages, daily study hours bar charts, subject time distribution, and streak monitoring.
- 🌙 **Dark & Light Mode**: Clean, elegant UI with smooth glassmorphism and modern typography.
- 💾 **Export & Backup**: Export your study sessions and data to Excel (`.xlsx`) or JSON backup.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/srrahulchauhan/studytracker.git

# Enter the project folder
cd studytracker

# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
